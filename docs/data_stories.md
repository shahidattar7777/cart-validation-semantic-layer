# Synthetic data: what's planted and where the numbers come from

All data is synthetic and generated by `python -m datagen.generate` (default seed 42). The stories below hold for any seed; `scripts/verify.py` checks them. Batch, lot and record IDs are stable across seeds. Measured values vary.

**Spoiler warning:** don't give this file to the agent. It's the answer key.

## Scale

55 batches (47 PD, 3 engineering, 5 PPQ) from 34 leukopaks and 18 healthy donors, January–August 2026. Batches start Tuesday to Friday, so leukopak collection is never on a weekend. There are 7 unit-operation tables, about 660 QC results, about 58,000 hourly historian points, and 58 spec items across 8 validated systems. The validation package has 24 protocols, 53 test cases and 92 executions, plus 59 risk rows, 7 deviations, 5 CAPAs and 5 change controls. Counts are for seed 42.

**Decoys** (correct answers must *not* include these):

- Requirements verified only through their FS / CS / DS (for example URS-LIMS-003 and URS-LIMS-004)
- Low-risk requirements verified by supplier documentation or inspection
- Alarm requirements with OQ but no PQ, where PQ isn't expected
- The IL-2 lot also stored in FRZ-80-02. It's only used by PV1 batches, so PV2 engineering runs rule it out.

## Where the process ranges come from

The values are plausible ranges informed by published work. They are not fitted to any dataset.

| Quantity | Synthetic range | Basis |
|---|---|---|
| Process shape: CD4/CD8 selection, CD3/CD28 activation, lentiviral transduction about 24 h post-activation, G-Rex expansion, 8–12 day process | as modeled | Luostarinen et al., *Sci Rep* 2025 (19-FiCART: 12-day semi-automated process with CD4/CD8 enrichment and LV transduction); Vormittag et al., *Curr Opin Biotechnol* 2018 review; Dias et al., *Mol Ther Methods Clin Dev* 2024 review |
| Final CAR+ viable cells | about 0.1–1.4 ×10⁹ (PV2.0: 0.1–0.5 ×10⁹) | Below the > 2×10⁹ CAR+ cells reported for the 12-day 19-FiCART process, as expected for a shorter 8–10 day culture with smaller seeding |
| %CAR+ at MOI 5 | 30–45% | Typical range across the reviews above |
| VCN | bulk about 0.1–3.8 copies/cell; per CAR+ cell about 1.2–5.0; internal limit 5.0 per CAR+ cell | FDA CAR-T guidance (Jan 2024): report VCN and justify the limit by risk assessment; it discusses VCN per transduced cell. "5" is an industry convention, not an FDA number. |
| Release viability ≥ 70%, CD3 ≥ 80% | internal specs | Common internal specifications. Product-specific in reality. |

Validation content (requirements, acceptance criteria, alarm limits) is illustrative. Values like ±0.5 °C incubator uniformity are typical but site- and vendor-specific.
